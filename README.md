# ⚡ ArbLab — инференс-арбитраж (Vast.ai → OpenRouter)

**Модель заработка:** арендуем GPU дёшево на маркетплейсе Vast.ai, поднимаем
OpenAI-совместимый сервер (vLLM) с ходовой открытой моделью и листим его на
OpenRouter (10M+ разработчиков, трафик роутится автоматически — клиентов
искать не надо). Маржа = цена токенов на OpenRouter минус аренда.

## Почему это работает
- Одинаковые модели на OpenRouter стоят у разных провайдеров **до 14 раз по-разному**
- Спред аренды: A100 на Vast от **$0.40/ч** против $1.79 (RunPod) и $2.79 (Lambda)
- Перепродажа голых VM запрещена (ToS), но **инференс — легальный товар**: мы продаём токены, а не аренду

## Состав репо
| Путь | Что делает |
|---|---|
| `tools/market_watch.py` | каждые 2 ч: цены Vast + цены токенов OpenRouter → расчёт маржи → `data/market.json` |
| `index.html` | панель: цены железа, маржа по связкам, статус проекта |
| `deploy/onstart.sh` | one-click поднятие vLLM на арендованной карточке |
| `docs/launch_guide.md` | пошаговый запуск + черновик заявки в OpenRouter Providers |

## Риски (честно)
- **Утилизация**: OpenRouter роутит по цене/скорости/аптайму — надо быть дешёвым и стабильным
- **Выплаты из РФ**: Vast принимает крипту; условия выплат OpenRouter проверяются на этапе заявки (см. launch_guide)
- **ToS**: продаём токены (легально), перепродажа голых инстансов запрещена — этого не делаем
