# Автопилот arb-lab: бесплатные лазейки и архитектура

## Схема: мозг без сервера

```
GitHub Actions (бесплатно, публичный репо) — контроллер 24/7-ish
   |  каждые 2 часа: market_watch.py -> data/market.json -> панель
   |  (опция, после топ-апа): sniper.py -> сам создаёт/убивает инстансы Vast
   v
Vast.ai спот-инстанс (interruptible, ~50% дешевле on-demand)
   |  vLLM + открытая модель, onstart.sh
   v
OpenRouter Providers -> трафик 10M+ разработчиков -> маржа
```

## Лазейки, на которых всё держится (легальные)

1. **Публичный репозиторий = неограниченный бесплатный GitHub Actions.**
   Это наш "бесплатный VPS": cron каждые 2 часа, без кредитки. VPS не нужен, пока не нужен непрерывный цикл <2 часов.
2. **Vast interruptible (спот) — та же карта за ~50-60%.**
   Инференс stateless: прерывание не страшно, снайпер просто пересоздаёт инстанс.
3. **Дневные колебания цен 4-7x:** ночью и в выходные 4090/A100 проседают.
   Панель (\"Спот-сделки\") показывает самые дешёвые офферы с ID — можно брать руками,
   а можно автоматизировать (sniper.py).
4. **Oracle Cloud Always Free (ARM, до 24GB RAM)** — запасной бесплатный "VPS"
   для постоянного контроллера, если Actions-интервала не хватит.
   В 2026 лимит урезали — проверять при регистрации, нужна карта для верификации.
5. **OpenRouter batch-эндпоинты** (:batch, ~50% цены) — как покупатель дешёвый трафик;
   как провайдер — наш потолок это обычная цена.

## Что НЕ работает (проверено, не тратить время)

- **Salad на VPS/виртуалке** — платформа для домашних ПК, VM и датацентровые IP не пропускает.
  Salad годится только для своей физической видеокарты дома.
- **Перепродажа голых VM** — прямой запрет ToS Vast. Продаём токены, не мощность.

## Интеграция с нашей экосистемой

- **quantum_lab** (эволюционный конвейер): когда понадобится дообучение моделей,
  sniper-логика ловит окно дешёвого H100 (спот-ночь/выходные) вместо on-demand цены.
  Триггер: tools/evolution_pipeline.py вызывает sniper.py с GPU=H100 и MAX_PRICE ниже медианы.
- **market_watch deals[]** — общий источник правды: и панель, и sniper читают один рынок.
- **Панель arb-lab** — cockpit: маржа связок + спот-сделки + статус.

## Как включить автопилот (когда будет топ-ап)

1. Топ-ап $20-50 криптой на vast.ai, создать API-ключ.
2. Секрет репозитория: Settings -> Secrets -> VAST_API_KEY.
3. Запустить sniper вручную (Actions workflow_dispatch) или python3 tools/sniper.py.
4. Первый запуск проверить тело create-запроса по docs.vast.ai (схема периодически меняется).
5. Инстанс поднялся -> vLLM жив -> заявка в OpenRouter Providers (docs/launch_guide.md).
